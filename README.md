# KK Studio — ApexPlanet Internship Task 4

A responsive front-end project built using **HTML, CSS, and JavaScript**. It combines the three implementation requirements listed in the ApexPlanet Web Development Internship PDF (Task 4, page 8).

## Features

### 1. Personal Portfolio
- About/profile section
- Selected projects and skills
- Contact form with browser-side required-field and email validation
- Responsive layout for desktop, tablet, and mobile

### 2. Notes App with localStorage
- Add notes with a title and body
- Search notes
- Delete notes
- Notes are saved and retrieved using the browser's `localStorage`

### 3. Product Listing Page
- Filter by category
- Filter by maximum price
- Sort by rating, low-to-high price, or high-to-low price
- Responsive product cards and empty-state message

## Run the project

1. Download or clone this repository.
2. Open `index.html` in a modern browser, or open the folder in Visual Studio Code.
3. Optional: use the Live Server extension in VS Code and click **Go Live**.

No package installation or build step is required.

## Files

- `index.html` — page structure
- `style.css` — visual design and responsive styling
- `script.js` — notes persistence, contact validation, product filtering and sorting
- `README.md` — project documentation

## Notes

- Notes are stored in the current browser and device. They are not synced to other devices.
- The contact form is a front-end demonstration; it validates fields but does not send an email or store submissions on a server.
- Product data is sample/demo data, not a live store or real inventory.
